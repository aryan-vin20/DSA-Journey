Time complexity -> NOT the actual time taken but amount of time takenas a function of input size(n)
*ek code ko run hone me different time lag skta hai on different machine(mac,windows) and differentplatform(leetcode,codeforces)
but time complexity for a given algorithm is same everywhere!

mainly 3 types -> 1.Worst case(Upper bound) -> Notation -> O(Big O) _placement perspective se sirf yahi important hai !
                  2.Best case(lower bound)-> Notation -> Omega
                  3.average case -> Notation -> theta

Steps : 1.once you get the function ignore constants for calculating Time complexity
        eg. 4n^2 + 6n + 55   ->   n^2 + n + 1
        2.pick the largest term(n ko change krne par jo term sabse jyada badh rha hai!)
        eg. n^2 + n + 1   ->   n^2
